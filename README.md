# Backseat website

Privacy policy, terms of use and support page for Backseat, an unofficial fan app for Grand Theft Auto VI. Served by GitHub Pages from `main` at https://getbackseat.app/ (the `CNAME` file holds the domain).

- `privacy/` and `terms/`: the app's Settings and its App Store listing link to these two addresses.
- `support/`: the contact address; the listing's Support URL points here.
- `index.html`: a short page about the app. `404.html`: any other address.

Backseat is not affiliated with, endorsed or sponsored by Rockstar Games or Take-Two Interactive.
